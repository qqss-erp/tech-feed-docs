# Version 25.6.1

We are pleased to share the latest updates and enhancements introduced in **Version 25.6.1**.  
Below are the key features and improvements, along with their respective locations for easy reference.

---

##  New Features

### 1. Invoice Report Enhancement
**Location:** You can access Invoice report under **Sales → Report**.

**Details:**
- In search criteria, **Sales Type** dropdown with options: `Export` and `Domestic`.
- New columns added in the report, Excel, and print views:
  - **CGST**, **SGST**, **IGST**
- Added **Due Date**, calculated as *Payment Terms + Ship on Board Date*.
- Added **Total Value with Tax** = Invoice Value + GST (CGST + SGST or IGST).
- Added **Total Value without Tax**.
- Introduced **Custom Excel Export** option:
  - Users can select/unselect fields for export.
  - Selected fields remain saved until logout.

---

### 2. Auto Generate Feature in Supplier PO
**Location:** You can access Supplier PO under **Purchase → Operations**.

**Details:**
- Implemented **auto-generate feature** for Supplier PO number.
- Once the user clicks **ADD**, a Supplier PO is created with an auto-generated number.
- If the PO is saved in draft, a **separate draft auto-generated PO number** is created.
- After approval, the Supplier PO retains the **normal auto-generated PO number**.

---

### 3. Petty Cash and P&L Head Changes
**Location:** You can access Petty cash Report under **Accounts → Report**.


**Details:**
- In **P&L Screen**, allow *space* and *special characters* in Heads Input.
- **Payment mode** dropdown defaults to **Cash** in Miscellaneous Screen.
- **Reload not required** in Miscellaneous Payment once submitted.
- Added **Description near Voucher Number** in Petty Cash Excel.
---

### 4. Invoice (Beta) Enhancement
**Location:** You can access Invoice (Beta) under **Sales → Operations**.

**Details:**
- **Place of Supply** auto-selected if only one option available.
- **E-Invoice Entry** now available in sub-tab with table view.
- **Transportation Mode** default set to *Road*.
- **Country of Origin of Goods** auto-selected when only one option available.
- **Invoice Line Items** now include *order-wise packing checklist*.
- **Invoice Status** available under Invoice (Beta) sub-tab.
- Status dropdown and changes are hidden in sub-tabs.
- For **Cancelled Invoices**, sub-tabs appear without **Submit** button.
- **Invoice Line-Item Table** alignment and scroll improvements; header is now fixed.
- **E-Invoice Fields** added at tab level:
  - IRN Number  
  - Acknowledgement Number  
  - Acknowledgement Date  
  - E-Way Bill Number  
  - E-Way Bill Date  
- Old Invoice Screen displayed based on organization-level settings.
- **B2B Field** selected by default.
- If a bank is already linked to a customer, **re-selection is disabled**.
- **Preview Options** added for:
  - Invoice  
  - Packing Checklist  
  - SCOMET  
- A new **Preview** button allows document preview in popup.

---

### 5. Payment Advice
**Location:** You can access Payment Advice under **Accounts → Operations**.

**Details:**
- Displays supplier-wise payment details based on **GRN Invoice payments**.
- Shows **invoice amounts**, **paid amounts**, and allows generating a **formal Payment Advice document** for suppliers.

---

### 6. Non-Returnable DC Generate
**Location:** You can access Non Returnable DC Generate under **Purchase → Operations → Non-Returnable DC**.

**Details:**
- Heading changed from **Non-Returnable DC** to **Delivery Challan**.

---

##  Enhancements

### 1. Control Task Rework Sub-tab Validation
- Under **Rework**, line items cannot be submitted without editing values.
- New alert feature checks whether rework validations are performed before submitting.
- Once rework is completed:
- Tasks can be **approved** or **sent to pending validations** based on approval status.
- **Validations older than 6 months** under rework will not appear in **Task Serial No.** dropdown.
- If the exact serial number is searched, it will still display.

---

### 2. Amount in Words with Decimal Values
The following PDFs now display amount in words in the pattern:

>*“Twelve thousand five hundred rupees and thirty-five paise only.”*

**Applicable Documents:**
- Supplier PO  
- Returnable DC Out  
- Supplier Job Work Out  
- Job Order  
- Non-Returnable DC

- Performance fixes and optimizations for improved **system stability** and **responsiveness**.
