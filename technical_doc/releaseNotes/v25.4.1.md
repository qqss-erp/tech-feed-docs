We are pleased to share the latest updates and enhancements introduced in Version 25.4.1. Below are the key features and improvements, along with their respective locations for easy reference.
 
## New Features
 
### 1. Returnable DC OUT
- **Location:** Purchase -> Operations -> Returnable DC Out  
- **Details:**
  - New feature introduced now user can cancel returnable DC Out.
  - Cancel Button: Enabled only if the total inward quantity is 0.
  - Returnable DC Out status:
    - Placed: When all line-item quantity = 0.
    - Partially Received: At least one item has inward quantity > 0.
    - Received: All line items received.
  - Returnable DC Out pdf generate is now available.
 
### 2. Sales Other Invoice
- **Location:** Sales -> Operations -> Sales Other Invoice  
- **Details:**
  - Name Change: “Service Invoice” renamed to “Sales Other Invoice”.
  - Invoice Type: Users can now select between Service Invoice and Other Invoice types when creating.
 
### 3. Invoice
- **Location:** Sales -> Operation -> Invoice  
- **Details:**
  - In the search screen, separate "Generate Invoice" types have been consolidated into a single dropdown. Users can select the desired type from the dropdown to generate the invoice.
  - Selecting an option triggers a confirmation pop-up before generation.
 
### 4. Control Plan
- **Location:** Production & Quality -> Master -> Control Plan  
- **Details:**
  - New status dropdown field added in control plan master.
  - Active status is default when creating control plan.
  - When a control plan is marked Inactive, it will not appear in any screen throughout the application that references control plans.
  - Inactive logic does not affect report-related screens.
 
### 5. Employee Attendance Upload
- **Location:** HR & Administration -> Operation -> Employee Attendance Upload  
- **Details:**
  - New Feature: Employee Attendance Upload screen added.
  - Access Control: Only HR Head can access.
  - Functionality:
    - Upload employee attendance data, including past records, via Excel.
    - Facilitates bulk attendance uploads.
    - For more details, refer to the DMeX Pro User Manual.
 
### 6. Attendance Generate
- **Location:** HR & Administration -> Report -> Attendance Generate  
- **Details:**
  - New Feature: Employee Attendance Generate screen added.
  - Access Control: Only HR Head can access.
  - Functionality:
    - Generate employee attendance in Excel format for easy use.
    - Users select the Report Generate Month to create reports for that month.
    - For more details, refer to the DMeX Pro User Manual.
