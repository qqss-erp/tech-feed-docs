We are pleased to share the latest updates and enhancements introduced in Version 25.3. Below are the key features and improvements, along with their respective locations for easy reference.
 
## New Features
 
### 1. Invoice Search
- **Location:** Sales -> Operations -> Invoice  
- **Details:**
  - Retains previously entered search fields (e.g., invoice number, date range) when navigating back from the Add/Edit Invoice screen.
  - Search limited to a 12-month date range.
 
### 2. Planning Report
- **Location:** Production & Quality -> Report  
- **Details:**
  - A new Planning Report added for improved machine scheduling and operational management.
  - Divided into sections for streamlined planning.
 
### 3. Part Management Enhancement
- **Location:** Design & Development -> Master -> Part  
- **Details:**
  - A new field, "Latest Part," is introduced in the Part Master.
  - If set to "Yes," the part is highlighted in green on the Part Search screen.
 
### 4. Purchase Inward Process Update
- **Location:** Store -> Operations -> Purchase Inward  
- **Details:**
  - Users can upload a file or provide a due date for supplier POs.
  - If no file is uploaded, the status displays as "Not Uploaded."
 
### 5. Multi-Select for Address Types
- **Location:** (Not explicitly mentioned in the original document)  
- **Details:**
  - Users can now select multiple address types (Billing & Delivery) simultaneously.
 
### 6. Supplier PO Delay Mail Automation
- **Location:** HR & Administration -> Email Config -> Supplier PO Delay Mail  
- **Details:**
  - Allows users to configure email recipients for automated daily PO delay notifications.
 
### 7. MTTR & MTBF Target Management
- **Location:** Maintenance -> Master -> MTTR & MTBF Target  
- **Details:**
  - New master screen for setting MTTR & MTBF targets for maintenance tracking.
  - Refer to the DMeX Pro user manual for more details.
 
### 8. MTTR & MTBF Report
- **Location:** Maintenance -> Report -> MTTR & MTBF Report  
- **Details:**
  - Displays MTTR & MTBF data using Bar and Line charts.
  - More details available in the DMeX Pro user manual.
 
### 9. Control Item Validations Enhancement
- **Location:** Inward Inspection, Special Process, Outsource Screens  
- **Details:**
  - CMM control item validation improved.
  - Optional CMM values are highlighted in sky blue.
  - Out-of-spec values marked in red, in-spec values in green.
 
### 10. Customer Job Work Reorganization
- **Location:** Stores  
- **Details:**
  - Job Work IN & OUT screens and reports moved to Stores for better organization.
  - They remain visible under the Sales menu as well.
 
### 11. Material Inward Management
- **Location:** Purchase -> Operations -> Material Inward  
- **Details:**
  - New screen added for managing material inward inspections.
  - Refer to the DMeX Pro user manual for details.
 
### 12. Employee Profile Picture Upload
- **Location:** HR & Administration -> Master -> Employee  
- **Details:**
  - Users can now upload profile pictures (limited to 15KB - 20KB).
 
### 13. Star User Recognition Feature
- **Location:** HR & Administration -> Master -> Star User  
- **Details:**
  - Displays top user’s picture on the login page.
  - Users can set an effective date and expiry date for the display.
 
## Enhancements
 
### 1. JS Report for Invoices
- **Location:** Organisation Details -> Default Template Selection  
- **Details:**
  - Invoice templates now available in JS report format.
 
### 2. Heat Serial Number Display in Control Task
- **Location:** Control Task Screen  
- **Details:**
  - Heat Serial Number is now displayed alongside the reference number for easier identification.
 
### 3. Backend Performance Fixes
- Various backend optimizations to enhance system speed and stability.
