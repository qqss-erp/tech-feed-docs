# Version 25.5.1  
 
We are pleased to share the latest updates and enhancements introduced in Version 25.5.1.  
Below are the key features and improvements, along with their respective locations for easy reference.  
 
---
 

 
### 1. Non-Returnable DC format for PDF Generation  
-- **Location:** You can access Non-Returnable DC under **Purchase → Operations**.
- **Details:**  
  - If **Remarks** is provided, it will be displayed in the PDF document.  
  - If **Notes** is provided, it will be displayed in the PDF document.  
  - If both **Remarks** and **Notes** are provided, both must be displayed in the PDF document.  
    
 
---
 
### 2. Chart Report Module  
-- **Location:** You can access OEE Graph under **Production & Quality → Report**.
- **Details:**  
  - Enables users to view various **OEE and performance reports** through interactive **Echart visualizations**.  
  - Accessible via a new sidebar link: **Info Graphics / OEE-Charts**.  
  - Supports multiple report types: Month-wise, Day-wise, Operator Idle Time, Operator with Idle Time, Machine-wise, Day-wise production count.  
  - Additional features: **Theme toggle**, **Carousel navigation**, **Modular styling**, **Standalone Angular component**, **Sidebar & routing updates**.  
   
 
---
 
### 3. MTTR / MTBF Average Values  
-- **Location:** You can access MTTR/MTBF Report under **Maintenance → Report**.
- **Details:**  
  - Feature added to **MTBF and MTTR chart reports**.  
  - The application now computes the **arithmetic mean of all MTBF values**, rounded to **two decimal places**.  
  - If no MTBF values are available, the mean defaults to **Zero**.  
   
 
---
 
### 4. New Maintenance Type in Machine History  
-- **Location:** You can access Machine History under **Maintenance → Operations**.
- **Details:**  
  - Added new maintenance type option: **Breakdown**.  
  - Available in both **Add** and **Search** screens under Maintenance Type dropdown.  
    
 
---
 
### 5. Invoice File Upload  
-- **Location:** You can access Invoice under **Sales → Operations**.
- **Details:**  
  - New sub-tab **Invoice File Upload** added with fields: Remarks, Invoice File Type.  
  - Users must provide **Remarks** and select the **Invoice File Type** (AWB File, E-Invoice, E-way Bill).  
  - File upload limit: **Max 3MB**.  
    
 
---
 
### 6. Maintenance Check Sheet Warning  
-- **Location:** You can access Control Task under **Production & Quality → Operations**.
- **Details:**  
  - If a selected machine does not have a **maintenance check sheet**, a warning is displayed:  
    *“Selected (machine name) machine doesn’t have any Maintenance Check List, please add the check list…”*  
  - Warning message updates dynamically based on the selected machine.  
  
 
---
 
### 7. GRN Date Back Limit  
-- **Location:** You can access Organization Details under **HR Administration → Master**.
- **Details:**  
  - New field **GRN Date Back Limit** added under Organization Details.  
  - Specifies the maximum limit for GRN date in **Purchase Inward** screen.  
  - Example: If created with current date, it can allow up to **10 days prior** in Edit mode.  
 
 
---
 
### 8. DQC Multi-File Upload  
-- **Location:** You can access DQC under **Packing → Operations**.
- **Details:**  
  - Allows uploading multiple files (pictures) using looping.  
  - Restriction: **4 files per question**, overall **50 files ('&lt;30MB`)**.  
  - Displays warning message if limit is exceeded.  
  
---
 
### 9. Control Task Rejection Validation  
- **Location:** You can access Control Task under **Production & Quality → Operations**.
- **Details:**  
  - **Previous behavior:** All validations were mandatory before part rejection.  
  - **Enhancement:** Validations are no longer mandatory for part rejection.  
   
 
---
 
### 10. Duplicate GRN Check  
-- **Location:** You can access Purchase Inward under **Store → Operations**.
- **Details:**  
  - On **Save/Submit**, the system checks if GRN number already exists.  
  - Displays a clear **error message** if duplicate is found.  
    
 
---
 
### 11. Heat Code Retention  
- **Location:** You can access Control Task under **Production & Quality → Operations**. 
- **Details:**  
  - **Heat Code** will now remain populated after submission.  
  - Available in both **Part Validation screen** and **Pending Validations tab**.  
  - Purpose: Reduce repeated data entry and improve operator efficiency.  
   
 
---
 
### 12. Production Schedule Edit Record  
- **Location:** You can access Production Schedule under **Production & Quality → Operations**.
- **Details:**  
  - Users can **edit a schedule record** only if the **current date** falls within its **From Date** and **To Date**.  
  - If outside range, the record becomes **read-only**.
