## Features
 
### 1. Control Task:
- **Location:** Production & Quality -> Operations -> Control Task -> Shift close  
- **Details:**
  - A new "Show Idle Time Details" button has been added to the Shift Close Idle Time pop-up.
  - When the user clicks this button, the calculation for idle time is displayed, helping operators and quality personnel easily understand the details.
  - The button is enabled only for Operator access and becomes active only after clicking the Shift Close button.
 
#### Screenshot: Idle Time Calculation Display
 
![Idle Time Details]
 
### 2. Control Task:
- **Location:** Production & Quality -> Operations -> Control Task  
- **Details:**
  - A new "Idle Time Details" button has been added to the Control Task screen.
  - When the user clicks this button, it displays the idle time booked in the Idle Time Admin Master for the selected machine.
  - The button is enabled only for Operator access and becomes active only after clicking the Shift Start button.
 
### 3. Part:
- **Location:** Design & Development -> Master -> Part -> Standard Reference  
- **Details:**
  - A Delete option has been added to the Standard Reference sub-tab.
  - Users can now delete an existing standard reference.
  - A confirmation pop-up will appear before the deletion to prevent accidental removal.
 
### 4. Purchase Inward:
- **Location:** Store -> Operations -> Purchase Inward  
- **Details:**
  - Duplicate validation is added for DC number and Invoice number.
  - When user gives duplicate entry for DC number or Invoice number in submit pop-up screen, confirmation is required.
  - If the user still wants that duplicate entry, they can simply click confirm to move further.
 
### 5. DMeX Pro User Manual:
- **Location:** DMeX pro user manual  
- **Details:**
  - A DMeX Pro Manual Documentation link has been added at the top of the Marketing menu section.
  - The same link is also available near the user profile for quick access.
  - This helps users understand all aspects of the application easily.
 
### 6. Assembly:
- **Location:** Assembly  
- **Details:**
  - New assembly menu added in application for tracking and managing the assembly.
  - For detailed explanation of this feature, please refer to the DMeX Pro user manual.
 
### 7. RFQ:
- **Location:** Marketing -> Operation -> RFQ  
- **Details:**
  - New RFQ menu added in application for tracking sales quotation and related activities.
  - For detailed explanation of this feature, please refer to the DMeX Pro user manual.
 
## Enhancements
 
### 1. Idle Reason Field Fix:
- Previously, the idle reason field was not clearing properly in the Scheduled Maintenance screen. This issue has now been fixed.
 
### 2. Searchable Heat Serial Number Dropdown:
- In the Control Task screen, the Heat Serial Number dropdown is now searchable, making it easier to find serial numbers.
 
### 3. Excel Export Feature:
- An Excel Export button has been added in the Store Consumption Search screen, allowing users to download data in Excel format.
 
### 4. Process Order Visibility Update:
- For convenience, process orders with -1 and 0 are now hidden in the Control Plan Process screen.
 
### 5. Backend Performance Fixes:
- Various backend errors have been fixed to improve speed and enhance system stability.
